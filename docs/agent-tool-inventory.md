# Agent Tool Inventory

Generated by `go run ./cmd/agenttoolinventory`; CI rejects drift. Provider routing, HTTP paths and internal versions are intentionally excluded from this model-facing inventory.

Removed legacy contracts: account source/subscription tools, confirmation/proposal tools, `push_now`, `update_schedule`, `edit_task_playbook`, and `set_task_strictness`.

Intent-routed exposure rolls out in three stages: aggregate shadow diff with the legacy surface unchanged, Feishu Owner canary, then explicit allow-all. Owner canary and allow-all are mutually exclusive.
